# Network Engineer Labs

Hands-on notes and labs from my work as a network and security engineer: routing and switching, Palo Alto Networks firewalls, Linux, cloud networking, and Python automation. Each topic covers how the technology works, the commands to verify it, and how to troubleshoot it.

## Repository Structure

```text
network-engineer-labs/
├── Networking/         # TCP/IP, VLAN, OSPF, BGP, DHCP, DNS
├── PaloAlto/           # Security policies, NAT, GlobalProtect, troubleshooting, CLI cheat sheet
├── Linux/              # Commands, networking, permissions
├── Python/             # Ping sweep, subnet calculator, config backup
└── Interview-Notes/    # Networking, Cloud networking, Linux Q&A
```

## Highlights

- **[Palo Alto CLI Cheat Sheet](PaloAlto/CLI-Cheat-Sheet.md):** session and policy tests, drop counters, packet-diag captures, IPsec and GlobalProtect debugging
- **[Palo Alto Troubleshooting](PaloAlto/Troubleshooting.md):** a step-by-step method used in TAC cases
- **[Networking Interview Notes](Interview-Notes/Networking.md):** OSPF/BGP, STP, MTU, IPsec, and troubleshooting method
- **[Cloud Networking Interview Notes](Interview-Notes/Cloud.md):** AWS VPC, Transit Gateway, VPN, endpoints, and Kubernetes networking
